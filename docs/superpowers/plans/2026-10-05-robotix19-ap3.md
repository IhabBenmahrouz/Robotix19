# Robotix19 — AP3 « Club Robotix » : plan d'implémentation

> Exécution : en ligne dans la session (carte blanche donnée par l'utilisateur le 2026-10-05). Chaque tâche suit le cycle test qui échoue → code → test vert → suite complète verte.

**Goal :** Couvrir la grille AP3 (SQL Server /60, CodeIgniter /60) dans Robotix19.

**Spec :** `docs/superpowers/specs/2026-10-05-robotix19-ap3-design.md`

## Global Constraints

- Mêmes contraintes que l'AP2 (PHP Laragon, `--no-coverage`, dates ISO `Y-m-d\TH:i:s` ou `AAAAMMJJ` dans le SQL brut, charset utf8, `esc()`, CSRF, français accentué, pas de git).
- T-SQL : `CREATE OR ALTER`, `SET NOCOUNT ON` dans les procédures, déclencheurs écrits pour des insertions multiples (tables `inserted` / `deleted`).
- Tests : transaction annulée sur les deux connexions (CodeIgniter et PDO) ; les objets SQL créés par migration ne sont pas annulés (DDL hors test).

## Review Focus

1. **Insertion de plusieurs inscriptions en une requête :** un mail et un compteur juste pour chacune (test tâche 2).
2. **Animateur supprimé alors qu'il est remplaçant ou anime des événements :** pas d'erreur de clé étrangère, les références passent à NULL (test tâche 3).
3. **Pointage par un animateur qui n'est ni titulaire ni remplaçant :** refusé (test tâche 5).
4. **Connexion avec un pseudo en majuscules :** acceptée (collation insensible à la casse) (test tâche 4).
5. **Membre qui s'inscrit deux fois au même événement :** refusé proprement, sans erreur SQL affichée (test tâche 5).
